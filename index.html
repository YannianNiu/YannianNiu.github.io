📄 Publications

Accepted

VLDB '26
STEM2: A Fast and Space-efficient Data Structure for Exact Multi-Set Membership Queries
Yannian Niu, Song Han, Minmei Wang
52nd International Conference on Very Large Data Bases (VLDB), 2026
A fast, space-efficient data structure for exact multi-set membership queries that outperforms related work in query throughput, memory cost, and accuracy. It is a promising primitive across networking and databases: traffic management and routing, distributed storage and caching, security and privacy-preserving systems, and data mining tasks such as customer purchase analysis.
NFV-SDN '25
MagicBox: Towards Consolidated Algorithms of Co-existing Network Functions on Heterogeneous Devices
Yannian Niu, Minmei Wang
IEEE Conference on Network Function Virtualization and Software-Defined Networking (NFV-SDN), 2025
An end-to-end system that takes the desired network functions, device specifications, and user-defined objectives as input, then automatically generates consolidated algorithms together with a deployment plan. A curated NF library makes it accessible to non-experts; experiments show it produces resource-efficient algorithms for co-existing NFs on heterogeneous devices.

Throughput-Efficient Communication Device Driver for IoT Gateways
Yannian Niu, Minghua Zhu
IEEE International Conference on Systems, Man, and Cybernetics (SMC), 2022
A user-space driver for IoT gateways. Moving packet forwarding out of the kernel and into user space bypasses the kernel stack and shortens the delivery path, raising throughput on the same hardware.
APNOMS '22
Assembler: A Throughput-Efficient Module for Network Driver of Edge Computing Gateways
Yannian Niu, Minghua Zhu
23rd Asia-Pacific Network Operations and Management Symposium (APNOMS), 2022
A module inside the gateway's network driver for small-packet-intensive traffic: it assembles small incoming packets into larger ones before transmission, and an adaptive assembly-size algorithm keeps data throughput and packet throughput in balance when the traffic pattern changes abruptly.

🔬 Ongoing Projects

Work in progress. Manuscripts still under review are described without titles or venues.

Lead Since January 2026

Exact Multi-Set Multi-Membership Query Solution for Metadata Indexing. Designed an exact multi-set multi-membership index that returns all containers containing a queried key, supporting point queries in log-structured key-value stores and policy checks in network access control. The index avoids both materializing each key's full membership list and probing every set, while providing exact answers with a memory footprint comparable to that of an approximate filter.

Lead Since July2026

Distributed KV Cache Retrieval for LLM Serving. Adapting our proposed exact multi-set multi-membership indexing solution to enable an LLM serving system to efficiently identify which distributed nodes hold the cached key-value blocks reusable by each request. Because this lookup lies on the critical path of every request, false hits from an approximate filter are particularly costly, as each triggers an unnecessary remote fetch that returns no reusable data.

Lead Since July 2026

Line-Rate Exact Membership Queries on Programmable Switches. Developing a P4 implementation of our proposed exact multi-set membership solution for programmable switches, enabling per-packet flow classification and multi-tenant ACL enforcement at Tbps line rates beyond what CPU-based solutions can sustain. The control/data-plane co-design on Intel Tofino addresses pipeline stage budgeting, stateful ALU register packing, and atomic control-plane updates for zero-downtime rule changes.

Contributor Since June 2026

Benchmarking LLM-Based P4 Programming. Built a scalable, adaptive benchmark for evaluating LLM-generated P4 programs, with network-function tasks derived from authoritative sources and packet-level oracles that verify both data-plane code and control-plane configurations on software and hardware switches.

Contributor Since March 2026

Intent-Driven Semantic Validation of P4 Programs. Designed an auditable, LLM-assisted property knowledge base that identifies requirements applicable to a P4 program from authoritative sources and turns them into executable tests for detecting semantic bugs.
